# Bamboo Notes — ランディングページ

AI統合型の英単語メモアプリ「Bamboo Notes」の 1 ページ LP。静的 HTML のみで、ビルド不要です。

## 構成

```
index.html            ページ本体
styles.css            デザイントークンとコンポーネント
bamboo-character.png  マスコット
.nojekyll             GitHub Pages で Jekyll 処理を無効化
```

## ローカルで見る

`index.html` をブラウザで開くだけです。

## GitHub Pages で公開する

1. リポジトリのルートにこれらのファイルを置いて push する
2. Settings → Pages → Source を `main` ブランチの `/ (root)` に設定
3. 数分後 `https://applicationsup12-eng.github.io/Bamboo-Notes/` で公開されます
